## 🔬 Metodología

1. **Planificación:** definición del área de estudio, objetivos y variables.
2. **Trabajo de campo:** registro de especies, datos ambientales y evidencia fotográfica.
3. **Procesamiento:** organización de fichas, matrices y coordenadas.
4. **Análisis:** cálculo de indicadores, tablas estadísticas y representaciones gráficas.
5. **Cartografía:** elaboración de mapas de ubicación y distribución espacial.
6. **Reporte:** integración de resultados, conclusiones y recomendaciones.

- Mapas dentro de `mapas_sig/practica-N/`
